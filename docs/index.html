PDF Studio

PDF tools that run on your own computer.أدوات PDF تعمل على جهازك، بدعم كامل للعربية.

Merge, split, compress, OCR, edit text in place and more, without uploading a single file. Free and open source, for Windows.ادمج وقسّم وضغّط وعدّل نص ملفاتك، من غير ما ترفعها على أي موقع. مجاني ومفتوح المصدر لويندوز.

  • No installation, about 130 MBمن غير تثبيت، حوالي 130 ميجابايت
  • No administrator rightsمن غير صلاحيات المسؤول
  • Free, AGPL-3.0مجاني، رخصة AGPL-3.0

What you can do with itإيه اللي تقدر تعمله بيها

Eleven tools in one window. Results can be chained, so you can merge, watermark, compress and protect in a row.إحدى عشرة أداة في نافذة واحدة. تقدر تكمّل على نتيجة أداة بأداة تانية: دمج ثم علامة مائية ثم ضغط ثم حماية.

Put a file in orderرتّب الملف

Merge files in the order you choose, split by pages, ranges or every N pages, and organize pages by deleting, rotating and reordering them with thumbnails.ادمج الملفات بالترتيب اللي تحدده، وقسّم بالصفحات أو النطاقات أو كل ن صفحة، ورتّب الصفحات بالحذف والتدوير وإعادة الترتيب مع صور مصغّرة.

Make it smallerصغّر حجمه

Compress analyzes the file first, then offers Lossless, Balanced or Maximum, with a side-by-side check against the original before you keep the result.الضغط يحلل الملف أولاً، ثم يعرض بدون فقد أو متوازن أو أقصى ضغط، مع مقارنة جنباً إلى جنب بالأصل قبل ما تحتفظ بالنتيجة.

Change the text itselfعدّل النص نفسه

Edit page erases or retypes text in the original font. Erasing really removes the old text from the file, it is not just covered.تعديل الصفحة يمسح النص أو يعيد كتابته بنفس الخط الأصلي. المسح يحذف النص القديم فعلاً من الملف، مش مجرد تغطيته.

Get content outاسحب المحتوى

Extract & convert to text, Word, Excel tables, images or PNG pages. OCR makes scanned pages searchable, Arabic included.الاستخراج والتحويل إلى نص أو Word أو جداول Excel أو صور أو صفحات PNG. والتعرف على النص (OCR) يجعل الصفحات الممسوحة قابلة للبحث، والعربي مدعوم.

Protect and finishاحمِ وأنهِ الملف

Security adds AES-256 encryption with permissions, or removes a password you know. Add text or logo watermarks, signature stamps and fill forms.الحماية تضيف تشفير AES-256 مع الصلاحيات، أو تزيل كلمة مرور تعرفها. وتضيف علامة مائية بنص أو شعار، وختم توقيع، وتعبئة النماذج.

In your languageبلغتك

The interface switches between English and Arabic, with right-to-left layout, and has light and dark themes.الواجهة تتبدّل بين الإنجليزية والعربية مع اتجاه من اليمين لليسار، وفيها ثيم فاتح وداكن.

Install it in a minuteثبّتها في دقيقة

  1. Download the zip and extract it into a folder you will keep, such as your Desktop.نزّل ملف الـ zip وفك ضغطه في فولدر ثابت، مثل سطح المكتب.
  2. Open the extracted folder and run PDF Studio.exe. Do not run it from inside the zip.افتح الفولدر وشغّل PDF Studio.exe. لا تشغّله من داخل ملف الـ zip نفسه.
  3. If Windows shows "Windows protected your PC", click More info, then Run anyway.لو ظهر تحذير "Windows protected your PC" اضغط More info ثم Run anyway للمتابعة.
Why the warning? The app is not code-signed yet, so Windows warns about new downloads. If Smart App Control is turned on, Windows may block it with no option to continue. In that case it cannot run on that computer until the app is signed.ليه التحذير؟ التطبيق غير موقّع برمجياً حتى الآن، فويندوز يحذّر من أي تحميل جديد. ولو كان Smart App Control مفعّلاً قد يمنعه ويندوز تماماً من غير خيار المتابعة، وساعتها لن يعمل على هذا الجهاز حتى يُوقَّع التطبيق.

To confirm the file is intact, compare its SHA-256 checksum with the one in the release notes.للتأكد أن الملف سليم، قارن بصمة SHA-256 للملف بالموجودة في ملاحظات الإصدار.

Why you can trust itليه تثق فيها

Your files stay putملفاتك لا تغادر جهازك

The app runs a small server on 127.0.0.1 only. The only network use is the optional check for a newer version.التطبيق يشغّل خادماً صغيراً على 127.0.0.1 فقط. الاستخدام الوحيد للإنترنت هو التحقق الاختياري من وجود نسخة أحدث.

Updates are signedالتحديثات موقّعة

The app offers a newer version with one click and refuses any update whose signature does not match.يعرض التطبيق النسخة الأحدث بضغطة واحدة، ويرفض أي تحديث لا يطابق توقيعه.
