PDF Studio

A free PDF toolkit for Windows that runs entirely on your computer, with full Arabic support.

Download for Windows Source code
About 130 MB · no installation · no administrator rights · free and open source (AGPL-3.0)

What you can do

Eleven tools in one window. Results can be chained, so you can merge, watermark, compress and protect in a row.

Merge & splitCombine files in the order you choose, or cut by pages, ranges or every N pages.
Organize pagesDelete, rotate and reorder pages with thumbnails.
CompressAnalyze first, then Lossless, Balanced or Maximum, with a visual check against the original.
Edit pageErase or retype text in the original font. Erasing really removes the old text.
Extract & convertText, Word, Excel tables, images and pages as PNG.
OCRMake scanned pages searchable, Arabic included.
SecurityAES-256 encryption with permissions, and password removal.
Watermark, sign & formsText or logo watermarks, signature stamps and fillable forms.

Private by design

The app runs a small server on 127.0.0.1 only. Your files stay on your computer. The only network use is the optional check for a newer version.

Get started

  1. Download the zip and extract it anywhere, for example your Desktop.
  2. Open the extracted folder and run PDF Studio.exe.
  3. If Windows shows "Windows protected your PC", click More info, then Run anyway.
The app is not code-signed yet, so Windows shows that warning for new downloads. If Smart App Control is turned on, Windows may block it with no option to continue. In that case it cannot run on that computer until the app is signed.

The SHA-256 checksum of the download is in the release notes, so you can confirm the file is intact.

Stays up to date

The app checks for a newer signed version and offers it with one click. It refuses any update whose signature does not match.
