OCR — make a scan searchable

  
For scanned or photographed documents. Requires Tesseract installed on this machine.

  

    
    

      

        

      

    

    

    
Installing Tesseract — Windows: the tesseract-ocr-w64 installer, and tick the
      Arabic language data. macOS: brew install tesseract tesseract-lang.
      Linux: sudo apt install tesseract-ocr tesseract-ocr-ara.

    

  







  
Compress

  
Make a large PDF smaller. Start with Analyze to see what is taking up the space.


  

    
    

    

  


  

    Choose how far to go
    

      

        
Keep quality exactly

        
No pixel changes

        
Removes wasted space only — repeated images stored once, streams recompressed, unused objects dropped. Every page comes out identical. Typically 5–40% smaller; more if the file was saved wastefully.

      

      

        
Smaller recommended

        
Looks the same

        
Also reduces images that are stored at more resolution than any screen or printer can show (above 200 DPI, down to 150). Fine for reading, email and normal printing.

      

      

        
Smallest

        
Trades quality for size

        
Reduces images to 96 DPI at lower JPEG quality. Best for sharing on screen or by email. Photos and scans become noticeably softer, and fine print may blur.

Fill PDF forms

  
Reads the form fields automatically and fills them in.

  

    
    

    

      
      
Arabic values are always flattened, whether or not the box above is ticked.
        Interactive PDF form fields render with built-in fonts that contain no Arabic glyphs, so
        an editable field would show empty boxes in most viewers. Flattening draws the text onto
        the page with a real Arabic font instead.
